# Figure Source Data

This directory contains source data aligned with the 2026-06-16 Sensors manuscript and GitHub Release `v1.0.2`.

Files `figure1_controlled_fault_protocol.csv`, `figure2_overall_architecture.csv`, and `figure3_speed_channel_repair_module.csv` document schematic figure elements rather than experimental measurements. Files `figure4_average_faulty_mae.csv` through `figure8_ablation_comparison.csv` provide the numerical source data for the corresponding manuscript figures.

Authoritative mapping:

- Figure 1: `figure1_controlled_fault_protocol.csv`
- Figure 2: `figure2_overall_architecture.csv`
- Figure 3: `figure3_speed_channel_repair_module.csv`
- Figure 4: `figure4_average_faulty_mae.csv`
- Figure 5: `figure5_faultwise_mae_gain.csv`
- Figure 6: `figure6_imputation_forecasting.csv`
- Figure 7: `figure7_horizon12_gain.csv`
- Figure 8: `figure8_ablation_comparison.csv`

Legacy exploratory figure-source exports from earlier manuscript versions are intentionally excluded from this release.
